# Testing WAKE 3.18.2 on the rower

The tablet is still on 3.11.1. Everything below was built and checked on the laptop but hasn't run
on the tablet yet, so screen layouts are the most likely thing to be off.

**While you test:** leave **STREAM ON**. Use the **📷 button** on any screen that looks wrong. It
lands on the laptop, where I can see it.

## 1. Install and launch (2 min)

- [ ] Install from the dashboard: **Install APK**, then **3.18.2**.
- [ ] A **Help tour** appears on first launch. Page through it.
- [ ] **Home:**
  - [ ] 20 cards and a progress row (week ring, level, streak, CONTINUE, SESSION ART, HELP).
  - [ ] Is anything cut off or too small?
- [ ] **Gauges:** take a few strokes.
  - [ ] **STROKE SHAPE** draws curves.
  - [ ] **KCAL** shows "~" and a number.
  - [ ] **WORK** counts up.

## 2. Calibrate (10 min) — the one that matters most

Tap **CALIBRATE** and follow the steps; see [CALIBRATION.md](CALIBRATION.md).

- [ ] **Boat distance** ticks after about 200 m.
- [ ] **Water drag** reaches 10/10 coasts.
- [ ] **Handle travel:** 3–5 slow pulls of 100 cm.
  - [ ] Is the spread under 8%?
  - [ ] What mm per pulse did it show?
- [ ] **Force:** 3+ steady pulls through the load scale.
  - [ ] What % did "force follows speed squared" show?
  - [ ] Write down each scale reading.
- [ ] **Results:** what were **measured watts** against **monitor watts**?

## 3. The big new screens (15 min)

- [ ] **River Explorer**
  - [ ] Is the river smooth (no stutter) and do the oars sweep on each stroke?
  - [ ] At a fork, does tapping a side choose it?
  - [ ] Does the minimap grow?
- [ ] **Zone Row**
  - [ ] Tap the plan chip to **PYRAMID**; the coloured timeline and segment countdown should appear.
  - [ ] Try **STREAK**.
- [ ] **Stroke Coach**
  - [ ] Do strokes draw over "your best", with a score and a tip?
  - [ ] Does the tip make sense?
- [ ] **Coast Flight**
  - [ ] Does it hover until 3 strokes, flap, and weave?
  - [ ] Does it fly low, with place names on the ground?
  - [ ] Is it smooth enough?

## 4. Quick passes (a minute or two each)

- [ ] **Race:** vs RIVAL, does it stay close? Tap **VS** to cycle opponents.
- [ ] **Crew Boat:** does even rowing raise the SYNC %?
- [ ] **Regatta:** finish a 500 m race, then check the division result.
- [ ] **Daily Row:** does today's challenge complete and tick the calendar?
- [ ] **Night Grid:** do lights come on as you hold power?
- [ ] **Row Runner:**
  - [ ] Does every stroke jump?
  - [ ] Does the dotted arc help with timing?
- [ ] **Canyon:** in FLY mode, are the rings reachable now? Tap MODE to try DRIVE.
- [ ] **Head Race:** are the four panels filled and moving?
- [ ] **Skyline:** do strong strokes drop 2–3 floor blocks?
- [ ] **Wave Rider:** does the right-hand bar show pocket and drift?
- [ ] **Collector:** does the boat glide between lanes?
- [ ] **Mega Pull:** do you see the record line and a NEW BEST?
- [ ] **Tug of War:** do the levels feel fair?
- [ ] **Rocket:** does 60 S TEST end after a minute?
- [ ] **Back home after a longer row:** does Session Art appear? Tap 📷 to send it to the laptop.

## 5. If you have them

- [ ] **Heart strap:** Diagnostics → **Find Heart Strap**, then Zone Row → **HEART** plan.
- [ ] **Handle sensor:** Diagnostics → **Find Handle**, then lean the handle at River Explorer forks.
- [ ] **Race SHARE / IMPORT** (the dashboard has already been restarted for this).

## What to tell me

For each screen: **works / looks wrong / feels wrong**, plus a screenshot. Leave WAKE with
**Exit**. Restart the tablet before going back to Ergatta.
